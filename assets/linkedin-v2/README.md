# LinkedIn portfolio slides (individual PNGs)

Eight 1200 × 1500 portrait PNGs, in numbered order, are the current presentation set. Each combines a redacted crop from a real n8n, Google Sheets or Slack screen with an explanatory caption. Red arrows are overlays; the application UI and decisions were not fabricated. All companies and enquiries shown are fictional.

The screenshots retain their source aspect ratio. The Slack cases include enlarged decision details for reading on mobile. The native Slack node in slide 5 has passed a read-only connection test; the six delivered demo messages shown in slides 6–8 used the earlier approved private webhook path. See [Demo and LinkedIn](../../docs/DEMO_AND_LINKEDIN.md) for the full interpretation and copy-ready post.
