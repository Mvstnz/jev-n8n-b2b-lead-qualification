# Screenshots: real evidence only

Add only real, redacted screenshots after testing. No fabricated workflows,
messages or model results. Hide account details, browser runtime URLs and secrets.
Review each final image visually and remove sensitive metadata.
Only then record its relative path, SHA-256 and reviewed_for_secrets=true in
checks/media_review.json. The release scanner verifies the hash, not the pixels.
See tools/README.md for the exact schema. Do not add the private setup ZIP.
