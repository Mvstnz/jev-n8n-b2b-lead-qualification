# LinkedIn portfolio slides in Roboto

These eight 1200 × 1500 portrait PNGs are the current presentation set. Their added titles, captions and explanations use [Roboto](https://github.com/google/fonts/tree/main/ofl/roboto) (SIL Open Font License). The source screenshots retain the original application typography and aspect ratio.

Each slide combines a redacted crop from a real n8n, Google Sheets or Slack screen with an explanatory caption. Red arrows are overlays; the application UI and decisions were not fabricated. All companies and enquiries shown are fictional. The Slack cases include enlarged decision details for reading on mobile.

The native Slack node in slide 5 has passed a read-only connection test; the six delivered demo messages shown in slides 6–8 used the earlier approved private webhook path. See [Demo and LinkedIn](../../docs/DEMO_AND_LINKEDIN.md) for the full interpretation and copy-ready post. The media hashes and secret-review record are in [media_review.json](../../checks/media_review.json).

Previous versions remain in [linkedin-v2](../linkedin-v2/) and [linkedin](../linkedin/).
